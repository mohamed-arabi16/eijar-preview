# Eijar (إيجار) — UI preview

Public image mirror for the **Eijar** rental-marketplace app preview (Mauritania · iOS + Android · Arabic-first RTL).

These are native screenshots of the current **UI prototype**, captured from the iOS build. The listings, prices, names and photos shown are **placeholder / mock data** for design purposes only — not real inventory. This repo exists solely to host the preview images so they can be embedded in the project's Notion pages.
